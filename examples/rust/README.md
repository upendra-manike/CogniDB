# 🦀 SyntricDB Rust Integration Example

This example demonstrates how to integrate **SyntricDB** into high-performance Rust applications using `tokio` and `reqwest`.

---

## 🛠️ How to Run

1. Make sure SyntricDB is running locally:
   ```bash
   syntricdb start
   ```

2. Run with Cargo:
   ```bash
   cargo run
   ```
