# 🦀 CogniDB Rust Integration Example

This example demonstrates how to integrate **CogniDB** into high-performance Rust applications using `tokio` and `reqwest`.

---

## 🛠️ How to Run

1. Make sure CogniDB is running locally:
   ```bash
   cognidb start
   ```

2. Run with Cargo:
   ```bash
   cargo run
   ```
