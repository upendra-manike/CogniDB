# 💻 SyntricDB Multi-Language Code Examples Repository

Welcome to the official **SyntricDB Examples Repository**! This folder contains fully functional, production-ready code examples demonstrating how to integrate SyntricDB across multiple programming languages and frameworks.

---

## 🚀 Available Language Examples

| Language / Framework | Description | Example Directory |
| :--- | :--- | :--- |
| 🍃 **Spring Boot 3 & JPA** | Standard `@Entity`, `@Repository`, `@Transactional`, `@Query` Vector Search | [`/examples/springboot-jpa`](./springboot-jpa) |
| 🐍 **Python** | HTTP REST integration with `requests`, vector search, and AI RAG | [`/examples/python`](./python) |
| 💚 **Node.js / JavaScript** | Async fetch REST integration and vector similarity queries | [`/examples/nodejs`](./nodejs) |
| 🔷 **Go (Golang)** | High-concurrency `net/http` REST integration | [`/examples/go`](./go) |
| 💜 **C# / .NET 8** | `HttpClient` REST integration with JSON payload serialization | [`/examples/csharp`](./csharp) |
| 🦀 **Rust** | Async `tokio` and `reqwest` integration | [`/examples/rust`](./rust) |
| 💻 **cURL / Shell** | Executable shell script for raw REST API calls | [`/examples/curl`](./curl) |

---

## ⚡ Quickstart Testing

Start your local SyntricDB instance:
```bash
syntricdb start
```

Run any of the language examples in their respective subdirectories!
