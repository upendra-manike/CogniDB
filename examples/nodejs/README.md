# 💚 CogniDB Node.js Integration Example

This example demonstrates how to integrate **CogniDB** into JavaScript / Node.js backend services.

---

## 🛠️ How to Run

1. Make sure CogniDB is running locally:
   ```bash
   cognidb start
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the script:
   ```bash
   npm start
   ```
