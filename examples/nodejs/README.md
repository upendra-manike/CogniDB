# 💚 SyntricDB Node.js Integration Example

This example demonstrates how to integrate **SyntricDB** into JavaScript / Node.js backend services.

---

## 🛠️ How to Run

1. Make sure SyntricDB is running locally:
   ```bash
   syntricdb start
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the script:
   ```bash
   npm start
   ```
