# 💻 SyntricDB cURL & REST API Example

This example demonstrates how to interact with **SyntricDB** directly via HTTP REST API using `curl`.

---

## 🛠️ How to Run

1. Make sure SyntricDB is running locally:
   ```bash
   syntricdb start
   ```

2. Run the shell script:
   ```bash
   ./api_requests.sh
   ```
