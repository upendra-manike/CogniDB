# 💻 CogniDB cURL & REST API Example

This example demonstrates how to interact with **CogniDB** directly via HTTP REST API using `curl`.

---

## 🛠️ How to Run

1. Make sure CogniDB is running locally:
   ```bash
   cognidb start
   ```

2. Run the shell script:
   ```bash
   ./api_requests.sh
   ```
